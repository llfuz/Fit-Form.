Fit & Form

A web-based fashion shopping platform that provides a personalized shopping experience with product customization and a complete e-commerce workflow.

Features

Product browsing and detailed product pages
Product customization by color, size, and fabric
Shopping cart and checkout
Wishlist and order history
User registration and login
User profile management
Admin dashboard
Product and order management
Form validation

Technologies

HTML
CSS
JavaScript
PHP
MySQL

About

Developed as a Web-Based Systems project at Imam Abdulrahman Bin Faisal University.
